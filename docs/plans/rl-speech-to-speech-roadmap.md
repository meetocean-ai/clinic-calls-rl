## 0. Where we are (verified 2026-10-07)

`tests/behavioral/env/` (2,393 lines): `reset(seed, family, tier, chaos)` seeds a fresh tenant in the local Medplum
(providers, daily 8–18 shifts, one patient, the scenario); `step_async(action)` runs a tool call or an utterance against
the simulated caller; `finish()` reads the FHIR end state back → binary reward. Families: booking, cancel, reschedule,
verify_fail_transfer. Tiers 1–3. Knobs: slot_taken, slot_taken_twice, existing_visit, dob_corrected, mind_change,
shared_phone, no_availability. Policies: random ≈ 0, oracle 1.0, production (real Reception → Scheduler, text mode).
Dataset/method hashes on every episode. Found B-134; production now 30/30, untrained Qwen3-8B 9/10 → **no gradient**.
Not built: trainer, env server, audio channel, reward model. PR #9 (feat/rl-training-e6) is config + runbook only.

Landscape (Oct 2026, details on the pitch page): no vendor sells healthcare RL environments; the only voice vendor sells
an eval; closed realtime models (gpt-realtime-2, Gemini Live, Hume) cannot be fine-tuned; open trainable S2S models
exist (Moshi/PersonaPlex/NemotronLabs VoiceChat/Qwen3-Omni); SpeechGym (Amazon) published the audio-native GRPO recipe
with no code; τ-voice and Full-Duplex-Bench v3 define the metrics; voice ≈ 79% of text task success.
